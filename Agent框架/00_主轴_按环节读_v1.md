# 主轴：按环节读（v1）

> **层**：**通用层**——整份可搬给别的项目。它只做指针，不复制内容；任何一条的权威版本仍在原文件里。


> **为什么有这份**：这 26 份规范原来有三种切法并存——按「层」横切（`00 人机接口`／`01 规则`／`02 流程`／`03 方法论`）、

> **主轴是 E0–E8**，因为活是按流程干的；「层」降为横切（在好几步都生效的东西）。

## 四·补、`02_流程层_交接防错` 与 `同步防断` 的分工

**先给事实**：`02` 里有 **40 条「四·补」**（不是十几条），共 38 KB；`同步防断` 是 5 种断法 ＋ 9 条规则，15 KB。

**它们不是重复，是同一类病的两种记录**：

| | `02_流程层_交接防错` | `同步防断` |
|---|---|---|
| 记什么 | **做什么**：交接状态机、四字段、开工前置清单，加上 40 条踩坑后的补丁 | **为什么会断、怎么机检**：五种断法 → 九条规则 → 谁拦它 |
| 读者 | 干活的人 | 改规则的人、接手的人 |
| 权威性 | 流程规矩以它为准 | 判法以它为准 |

**四处同族**（改一处要看另一处）：

| `02` 的补 | `同步防断` | 关系 |
|---|---|---|
| 四·补十二 跟进通道 | R1 通道关账前台账必须有 B 段 | 前者要「有地方记」，后者要「关账前回写」 |
| 四·补十三 作废要就地改 | R3 状态行是独立账，裁完回头销 | 同一件事：别只在文末声明 |
| 四·补二十一 结论必须回原文 | R5 挂作者必须引原话 | 前者管结论，后者管归属 |
| 四·补三十七 人工判断带复查条件 | R7 已定必须带证据 | 前者管复查，后者管证据形态 |

**不合并正文**，理由：`02` 的 40 条带着当时的措辞与教训，合并会丢历史；
`同步防断` 要的是可机检的形状，塞进 40 条会重新变成「读不完」。

**另有一条待清**：40 条补丁里有几条其实**已经被闸取代**（例：四·补十四 检查器自报范围 → `_gate` 的 `[scope]` 检查；
四·补三十四 花钱前公示 → `J-33`；四·补十九 引用只写名字 → `_anchor`）。
这些可以降级为一句「已被 X 覆盖」，`02` 能瘦一圈——但**要先逐条核**，我没擅自动。
