# packaging/templates/

这里是**给你自己项目用的空模板与起步文件**，不是本库的说明书。

| 文件 | 用途 |
|---|---|
| `gitignore` | 项目工作区的 `.gitignore` 底稿 |
| `常量台账.md` | 版本／路径／口径的单一来源登记处 |
| `版权与开源红线.md` | 授权范围与禁用材料 |
| `跟进通道.md` | 台账本体（唯一真相源） |
| `发布前检查清单.md` | 发布前逐条打勾 |
| `项目配置_空模板.json` | 项目配置样例 |

本库自己的说明书只有根目录 `README.md` 一份；装法与三条命令都在那里。
