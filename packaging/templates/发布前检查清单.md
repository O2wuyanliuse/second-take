# 发布前检查清单

> **这份是动作，`版权与开源红线.md` 是原则。**
> 那份回答「能不能」，这份回答「做没做」。
>
> 每次要往外发东西之前，从第一项走到最后一项。**不许跳。**

---

## 一、发之前逐项打勾（八项，一项都别跳）

### ① 权利边界核过了

- [ ] 翻过合同／协议原文，不是凭印象
- [ ] 「独家」「授权范围」「改编」这几条看过
- [ ] 如果签过平台：确认过「作者本人能不能在其他平台发布衍生内容」

> **过不了这一项，后面全部不用做。** 这是唯一一项「不确定就该停」的。

### ② 引用过了筛

- [ ] 逐句列出要用的原文片段（不是"大概有几句"）
- [ ] 每一句问过：**它是在传递信息，还是在传递感受？**
      —— 传递信息的删掉，传递感受的可留
- [ ] 没有引用关键信息点（反转、身份揭露、结局、核心设定）
- [ ] 总量克制：不能让看完的人不需要看原作

### ③ 声明贴满了三处

- [ ] 成品画面里（片头或片尾，停留够读）
- [ ] 发布文案第一段
- [ ] 简介／描述里

> **三处缺一不可。** 这是「非商业展示」这个定性成立的条件，不是可选项。

### ④ 不提供正文入口

- [ ] 视频里没有放原作链接／二维码
- [ ] 简介里没有导流到全文
- [ ] 没有「全文在 XX」这类引导

### ⑤ 没有商业成分

- [ ] 没挂车
- [ ] 没挂课／知识星球／社群
- [ ] 没有赞赏入口（含平台打赏）
- [ ] 没有品牌合作

> 有收入 → 「非商业展示」不成立 → ③ 的声明也就失效了。**两者是连着的。**

### ⑥ 没有夹带内部文件

- [ ] 画面里没有出现目录树、文件名、台账截图
- [ ] 没有露出对话记录／提示词全文（**提示词可以展示思路，但不能贴成品**）
- [ ] 没有露出别人的名字和联系方式

> 这条最容易漏：**文件树截图就等于文件本身**。你贴一张带文件名的截图，
> 别人照着名字就能问你要东西，而且你已经证明了它存在。

### ⑦ 文档没有整段连贴两遍

- [ ] 跑 `python 00_原著/_dupcheck.py`：**退出码 0 才算过**（它会打出扫了几份、跳过几份）
- [ ] 用 AI 补过段落的文件，回头看一眼：**新段进去了，旧段还在原位吗**

> 判据：**连续 3 行以上、逐字相同、并且紧挨着**（中间的空行也算一行，两边要一样）。
> 不分长短——贴多长都算，三段以下的重合才是正常写法。
>
> 这个脚本自己带自检：`python 00_原著/_dupcheck.py --selftest`，四例全过才说明判据还灵。
> 判据改过措辞的话，先跑自检再跑正检——**尺子歪了，量出来的绿没有意义**。
>
> **它宁可多报**：同样的短段落紧挨着出现两次（中间隔一个空行）也会被点名。
> 报出来看一眼就行，别看都不看就删——**漏报和误报的代价不对等**。
>
> 为什么要留这一项：这类错读起来是通顺的——贴重的那两段都是正经内容，不是乱码，
> 只有人恰好读到那一段时才看得见。等读者发现，已经发出去了。

### ⑧ 仓库还是私有的

- [ ] 检查过仓库可见性
- [ ] 没有误加协作者
- [ ] 没有任何 fork 到公开仓库

---

## 二、发完之后

- [ ] 存一份发布截图（时间、标题、播放量），**自己留证**
- [ ] 如果有任何一方（平台／合作方／原作者）提出异议——**立刻下架，不要争**

> 下架不丢人，也几乎不产生额外责任。
> **争论会产生**：一是把「不知情」变成「明知」，二是留下更多传播证据。

---

## 三、这份清单管不了的四个洞

诚实列出来，别以为打了勾就安全：

| 洞 | 为什么 |
|---|---|
| 看不到你的合同 | 它只能提醒你去翻，翻到什么算你的 |
| 「关键信息点」靠人判 | 同一句话，你觉得是氛围，平台可能觉得是剧透 |
| 商业成分的边界模糊 | 有一个「创作激励」算不算收入？平台和你的理解可能不同 |
| **只防「忘了做」，防不了「做错了」** | 打了勾不代表判断对 |

**最后一条是本质。** 清单保证你没漏步骤，保证不了你判断准确。
