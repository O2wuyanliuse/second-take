# 反向扫描白名单 —— 每个词都要写「为什么不是泄漏」
#
# 格式：词 = 理由
#
# 这份表存在的理由（跟 `_cost.py` 的「历史豁免」同一条）：
#   词表是从项目侧借来的，**借来的词不认识通用层的语境**。`通行证` 在项目里是设定词，
#   在通用层是「自己给自己发通行证」这句普通话。
#
#   不豁免 → 每次扫都红 → 红变日常 → 真泄漏那天没人看。**宁可只留 3 条真红。**
#
# 纪律：
#   ① 每条必须写理由。**光写词不写理由的，整行不算**（脚本会跳过并提示）。
#   ② 理由要能回答「为什么删掉它就说不清了」，答不上来就是真泄漏，别往这儿塞。
#   ③ 豁免是**永久可见的记账**，不是删除。表越长，越说明该改代码而不是加词。
