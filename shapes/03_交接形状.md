# 交接形状：换人接手时，靠什么把「现在在哪」传过去

> 一个长线项目最贵的损失不是做错一步，是**新来的人不知道哪些已经做过**，于是把做过的再做一遍。
> 每次重做的成本，等于之前那一遍的全部投入。

## 一、状态卡：一页，且能被校验

| 要写什么 | 为什么 |
|---|---|
| 现在在哪一步 | 不是「进度 60%」，是「哪一件在飞、哪一件收口」 |
| 下一步是什么 | 一句话，能直接开工 |
| 钱花了多少、还剩多少 | 必须标**口径**：是下单值还是实际扣费 |
| 一页的指纹 | 让「卡过期了」这件事可被发现，而不是靠人记得 |

**指纹怎么来**：把状态卡的几份来源（台账／清单／流水）算一个短哈希印在卡上。
源改了卡没重生成，哈希就对不上——**这是唯一能让「你读到的是旧状态」自动暴露的办法。**

## 二、交接件：四段，缺一段就会出事

| 段 | 内容 | 缺了会怎样 |
|---|---|---|
| 一、现状 | 数字都核过的表 | 新人拿旧数字做新决定 |
| 二、已收口 | 哪些**别再动** | 把做完的重做一遍 |
| 三、钱 | 已花／待批，带口径 | 重复花，或不敢花 |
| 四、下一步 | 能直接执行的一句 | 停在原地等指示 |
| 五、坑 | 形状比事件重要 | 同一个坑换个马甲再踩 |

## 三、回执：做完一件之后，怎么写回给主线

交接件是「我走了，告诉你我在哪」；回执是「我做完了，告诉你我做了什么」。
**方向相反，同一个风险：读的人看不到过程，只能看这张纸。**

| 段 | 内容 | 缺了会怎样 |
|---|---|---|
| 一、做完什么 | 一句话 ＋ 落点文件（带路径） | 主线不知道去哪看结果 |
| 二、动过哪些文件 | 清单，一行一个 | 出问题无法回滚，也不知道牵连面 |
| 三、**哪些是我编的、哪些没验证** | 逐条列，**不许用「已确认」充数** | **主线会把编的当真的，然后基于它做决定** |
| 四、红线 | 下游接手时别踩的地方 | 下一棒把踩过的坑再踩一遍 |
| 五、等一句话的 | 未决项，每条给出选项 | 停在那里等，或者自己猜 |

**第三段是这张纸的灵魂，也最容易被省。**

写「状态：已写入」很容易，可目录里可能根本没有那个文件。**没验证的必须自己说出来**——
主线没有你的现场，他唯一的现实来源就是这张纸。

**反过来：收方必须核，不能照抄。**

实测过一次：回执写「新增第 18 栏」，实际是第 17 栏。错一个数不可怕，
可怕的是**回执里的数字会被下一棒直接抄下去，中间没有人拦**。

所以回执件末尾留一栏给收方：

```
核对 ｜ 逐条对过什么 ｜ 改口几处（原处 → 现文）
```

**「原处 → 现文」不是格式洁癖**：只给现文，收方看不到原来写的是什么，
就没法判断是「改对了」还是「改出了新矛盾」。

## 四、决策与证据：三栏，缺一栏就是「机器说了算」

```
决定 ｜ 依据（原话或数字）｜ 否掉了什么
```

**为什么必须有第三栏**：只写「决定用 A」，读的人不知道 B 为什么被排除。
下次遇到类似情况，他会重新纠结一遍，或者**选回 B**——因为没人告诉他 B 已经试过。

**为什么依据必须是原话或数字**：
「作者认可」不是依据，「作者说过『对了对了，就是这个手感』」才是。
一条挂在人名下的结论，**如果引不出原话，它就获得了免疫**——没人敢质疑，也没人知道它是怎么来的。

## 五、四道自检（交接件写完，逐条过一遍）

1. 每个被提到的编号，在台账里搜得到吗？
2. 每一条「已定」，能引出原话或数字吗？
3. 同一件事，有没有两处说法不同？
4. 一个没读过项目的人，能不能按第三节的「下一步」直接开工？

第 4 条最狠也最有用：**答不出来，就说明交接件还是写给自己看的。**

## 六、最小可用版

只有三段也能交接：**现在在哪 ／ 下一步做什么 ／ 哪些别再动**。
但**「钱」这一段不能省**——它是唯一一个「错了不会报错、只会重复发生」的字段。
