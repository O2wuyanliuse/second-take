# templates/checks/_depmap.py 原始模块文档

来源：`templates/checks/_depmap.py`。本文保存外搬前的完整说明、事故史与表格；代码内只保留运行用法和本页指针。

依赖归属图 —— 判「一项检查能不能整项搬走」（2026-11-17，`G-958`）。

**为什么要有这支**：拆 `_consist.py` 时反复卡在同一件事上——「这个常量是它独占的，
还是别处也在用？」先前用正则 `^NAME =` 数，**漏判**（对齐空格、多行定义看不见），
于是每搬一批就冒出几个 `NameError`，再一个个补。正则判语法，本来就不该。

**它做什么**：用 `ast` 解析 `_consist.py` 与 `checks/*.py`，
- 列出每个模块的**顶层定义**（常量／函数／类）；
- 列出每个函数的**自由名字**（被读、但不是局部变量、不是参数）；
- 把自由名字映射回「哪个模块提供它」；
- 对每个检查，报：**独占**（只有它用）／**共用**（别的检查也用）／**来自包里别的模块**。

**怎么用**：
    python scripts/_depmap.py                # 全表
    python scripts/_depmap.py --check check_shot_columns
    python scripts/_depmap.py --md 输出.md    # 写成报告

**判据**：一项检查「独占 ＋ 只依赖 `_core` 注入的那几个」＝ **可整项搬**；
只要有一个共用名字，就得先决定：注入（保留单一份）还是降耦（把名字收进它的词汇表）。
