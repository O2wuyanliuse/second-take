# docs/internal · 考古层

> 这个目录里的东西**不是当前承诺**。它们是某一次审计、某一次打包留下的现场记录，
> 放这里是为了以后有人问「当时为什么这么改」时有原件可查，不是为了让人照着做。

## 里面有什么

| 文件 | 是什么 | 现在还算数吗 |
|---|---|---|
| `docs/internal/开源审计_20261117.md` | 转公开前的一次只读全历史审计（含一条真问题：本地孤儿分支里的旧 `_pack.py` 带过组织名） | 那**一条结论**算数；扫描范围是当时那个库，之后的条数不对 |
| `docs/internal/待脱敏清单.md` | 0.4.x 时代打包被验包工具拦下后的处置清单 | 四类处置与两道硬闸的血统算数；具体处数（189 处那些）是当时的快照 |

## 三条规矩

1. **不维护。** 这里不跟代码更新，发现对不上是正常的——它就是旧照片。
2. **不当依据引用。** 说明「现在怎么打包」引用 `docs/maintain/维护方法.md` 与 `docs/为什么值得信.md`；这里只回答「当时发生了什么」。
3. **不往里加新件。** 新的审计结论写进 `docs/为什么值得信.md` 或维护方法 §9；只有「一次性、结案即封存」的现场记录才进这个目录。

## 为什么单独放

`packaging/` 是**工具**目录：谁 clone 都要照着它跑。一份「当时的处数」混在里面，读的人会以为那是判据。
挪出来之后，`packaging/` 里只剩能跑的东西，这个目录只剩能查的东西。
